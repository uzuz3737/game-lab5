# Skybound Courier — LAB 5 First 3D Game

เกม 3D Platformer สไตล์ Low-Poly มี 2 ด่าน สร้างจาก 3D Platformer Starter Kit ของ Silver Demon Studios
ใช้ Godot 4.7.1 ตามเวอร์ชันที่ผู้ใช้เลือกในเครื่อง

## เปิดเล่น

เปิด project.godot ด้วย Godot 4.7.1 แล้วกด F6 ที่ scenes/main_menu.tscn หรือ F5 เพื่อเล่นทั้งเกม
กดปุ่ม เริ่มการเดินทาง ในเมนู

## วิธีเล่น

- WASD หรือปุ่มลูกศร: เดิน; เมาส์: หมุนกล้อง
- Space: กระโดด กดอีกครั้งกลางอากาศเพื่อกระโดดสองครั้ง
- Shift: วิ่ง; Esc: พัก/เล่นต่อ; R: เริ่มด่านปัจจุบันใหม่
- ด่าน 1 Moss Gardens: เก็บคริสตัล 8 ชิ้น หลบหนามและใบเลื่อย ข้ามเกาะไปประตู
- ด่าน 2 Amber Works: เก็บคริสตัล 10 ชิ้น หลบใบเลื่อยและเลเซอร์ที่เปิดปิดเป็นจังหวะ
- ประตูจะเปิดเมื่อเก็บคริสตัลครบ เข้าประตูด่าน 1 เพื่อไปด่าน 2 และประตูด่าน 2 เพื่อชนะ
- แท่น CHECKPOINT เป็นจุดเซฟ ตกเหวหรือโดนกับดักจะกลับจุดเซฟ พร้อมบวกเวลา 5 วินาที
- คริสตัลที่เก็บแล้วไม่หายเมื่อเกิดใหม่ ไม่มีการจำกัดจำนวนชีวิต

## โครงสร้าง

scenes/main_menu.tscn — เมนูหลักพร้อมฉากเกาะลอยฟ้า
scenes/level_1.tscn — สวนโบราณเขียวครีม พร้อมกับดักและสะพานเคลื่อนที่
scenes/level_2.tscn — โรงงานพลังงานสีส้มทอง พร้อมเลเซอร์และแท่นยก
scenes/player.tscn — Hooded Adventurer จาก Poly Pizza แทน Gobot
scripts/player.gd — Controller ที่ปรับจาก Starter Kit และ remap แอนิเมชัน
credits/ASSETS.md — แหล่งที่มาและรายละเอียดแอนิเมชัน

แต่ละด่านเป็น .tscn ที่มี geometry และ collision บันทึกจริง แก้ไขตำแหน่งใน Godot ได้
เกมใช้ shared materials และ model ตัวละครประมาณ 1.6 MB เพื่อให้โปรเจกต์เล็ก
MCP addon ใช้ช่วยทดสอบใน editor ไม่จำเป็นสำหรับตัวเกมที่ส่งออก
